# «Сигнал» — MVP 0.2 (контур III «Радар возможностей»)

Адрес: https://vldik-hue.github.io/opportunity-radar/signal/

**Статус 22.10.2026:** опубликованная демонстрация технической гипотезы, **не продаваемый SaaS** и **не подтверждённый источник дохода**.

## Что работает

- Ручные позиции: ввод цены и наличия, условие срабатывания, журнал событий.
- Автоматический источник **GitHub Releases**: официальный публичный API `https://api.github.com/repos/{owner}/{repo}/releases/latest`. Реально отслеживаются новые теги опубликованных релизов (демонстрационный источник; не магазин).
- Источник **открытый JSON API**: пользователь указывает HTTPS URL, путь до значения (например, `price.current`), условие: любое изменение, ниже/выше порога. Нужны разрешение CORS и соблюдение условий источника. Не нужно и нельзя вводить секретные токены в публичную форму.
- Кнопка немедленной проверки, периодическая проверка ~30 минут **только пока страница открыта**, уведомление браузера при предоставленном разрешении.
- Исходная проверка записывает базовое значение; последующее изменение порождает событие. Журнал хранится локально.
- Экспорт JSON/CSV, импорт локального бэкапа, удаление, пауза отдельных наблюдений.
- **Демо trial:** 7 дней до 10 автоматических позиций, после — 3. Отсчёт и лимит локальные, не защищены от обхода. Оплаты, аккаунтов, автопродления, удалённой аналитики и клиента-плательщика нет.

## Пройти технический тест

1. Открыть страницу, нажать «Демо на официальном API» → «Проверить все автоматически».
2. Убедиться, что появилась базовая версия и статус проверки, но журнал пуст: исходное наблюдение **не является новым событием**.
3. Для теста обнаружения события создать собственный доступный CORS JSON API и изменить одно поле между двумя проверками, либо сделать две ручные проверки одной цены: 3000 → 1800 при целевом пороге 2000. Должно появиться **одно** событие на переход через порог.
4. Экспортировать данные, импортировать обратно; проверить, что записи сохранились.
5. Открыть в новом браузере: данные в нём отсутствуют — пока нет сервера.

## Технический аудит 22.10.2026

- Исходный HTML и JavaScript созданы в подпапке `signal/`, корневой `index.html` радара не изменён.
- GitHub connector fetch_file подтвердил совпадение опубликованного содержимого после записи.
- TinyFish fetch_content подтвердил HTTP-доступность GitHub Pages по адресу выше.
- Проверка JS-синтаксиса успешна.
- Изолированный тест с подставными ответами API: `v1→v2` сформировал одно событие после базовой проверки; цена `2700→1950` при пороге `2000` сформировала второе. **Это тест логики на имитациях, не сквозной живой пользовательский тест.**

## До подключения денег и реальных клиентов

1. Проверить доступ к конкретному поставщику данных по лицензии/API и реальную полезность событий. Не обещать поддержку Авито/Ozon/WB или других сайтов без разрешённого технического подключения.
2. Найти 3–5 публичных повторяющихся запросов в **одной конкретной отрасли**, отделяя жалобы от готовности платить.
3. Тестировать бесплатный пример + платный результат или 7 дней trial; посчитать стоимость API, хранения, сообщений и поддержки, подтвердить внешним действием согласованный платежный интерес.
4. Добавить серверный планировщик, базу пользователей, аутентификацию, отписку и уведомления только при положительном сигнале спроса. Статический сайт сейчас не работает как фоновый 24/7 монитор.
5. Для подписки понадобится юридическая проверка договора/оферты, налогообложения, персональных данных и платежей.
