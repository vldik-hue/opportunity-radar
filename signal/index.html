Шаг 1

Для JSON API источник должен разрешать доступ из браузера (CORS). Не вставляйте ссылки с паролями и токенами.

2. Проверить и получить сигнал

При открытой странице автоматическая проверка повторяется примерно каждые 30 минут. При закрытом браузере проверок и системных уведомлений нет.

Бесплатная проверка гипотезы: 7 дней до 10 автоматических наблюдений, затем до 3. Это демонстрация будущих тарифов, не платная подписка.

Выгрузите наблюдения перед очисткой браузера. Данные не синхронизируются между устройствами.

Ограничения: нет серверной фоновой проверки, личного кабинета, оплаты, коммерческого SLA и гарантии доступности внешних API. GitHub Releases — рабочий демонстрационный источник для проверки механизма; он не является магазином. Для мониторинга товарных цен нужен законный и доступный источник данных поставщика.
«Сигнал» — экспериментальный продукт контура III проекта «Радар возможностей». Источники проверяются только по явному выбору пользователя. Информация носит справочный характер. Никаких заявок, покупок, внешних публикаций и платежей приложение не создаёт.
